#Part 1B: Sudoku Solver Using Backtracking + MRV

An intelligent 9 x 9 Sudoku Solver implemented using Backtracking Search enhanced with Minimum Remaining Values (MRV) heuristic.

## Requirements for running the solver:
Python 3.8 or higher
Standard Python Libraries 'sys', 'time', and 'csv'

## How to run solver
Run solver from the terminal by passing a path to a Sudoku grid file for example:

'''bash
python solver.py puzzles/easy.txt
